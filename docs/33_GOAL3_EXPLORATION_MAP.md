## 0. 目标层（终点）

**目标3 = 捕捉到战役中 AI（第三方势力）之间的战斗并成功加载，本地玩家自动旁观（IsSpectator 等价身份），可以看到纯 AI 互战。**

- **成功判据**：AI 内战加载出战斗场景 + 旁观身份 + 用户视觉确认纯 AI（对照 shogun2 四判据：battle_mgr 非 0 / 视觉确认 / IsSpectator=1 / 纯 AI 无玩家）。
- **已确证边界（勿重探，71 报告）**：
  - 官方通道直接复刻 = **不成立**（pending 脚本面纯查询；无强制加载/旁观 API；SPECTATOR 全在 MP lobby）。
  - 引擎层 b9 思路迁移 = **可行**（中-高工作量）；**b9 等价物候选 = 投票/就绪块**（`PRE_BATTLE_VOTING_SYSTEM::FACTION_VOTE`/`VOTING_SYSTEM_BLOCK` @0x34980A2/@0x34980D8、`FACTION_READY_TO_FIGHT` @0x3492208）。
  - 观测通道官方零成本可搭（PendingBattle/BattleCompleted 事件 + ai_only_battle_events）。
  - 唯一官方翻盘点 = `get_modify_pending_battle`（@0x346BBC8，可能性低，待反编译裁决）。
- **失败形态**：自动结算（无加载）/ 静默退出 / 卡死 / 无旁观身份（滑向目标1 语义）。

## 3. 技术路径层

### 3.1 官方翻盘点裁决（路线1 唯一悬念）

- **原理**：`get_modify_pending_battle` 若可写投票/就绪标志 → 官方通道达成（AGENTS §0 通道优先级生效）。
- **证据**：🔶 接口名存在 @0x346BBC8（71 报告 §1.2）；⬜ 方法集/可写性未知。
- **行动**：Ghidra xref @0x346BBC8 → 反编译 MODIFY_PENDING_BATTLE 方法集。
- **判据**：方法集含 setter（就绪/投票/加载标志）→ 升级为可行；只读字段 → 关闭（记录入 32 LogBook）。

### 3.2 b9 等价物定位（路线2 主攻——★2026-08-19 定案：动态优先，静态 xref 关闭）

- **原理**：3K 分叉判定函数（shogun2 FUN_105caa60 等价物）读投票/就绪标志 → 分支到（a）env 加载链 或（b）autoresolve 结算链；**b9 等价物 = 该函数输入集的某个就绪/投票位**。
- **证据**：🔶 三锚线字符串命中（§0）+ 类型名同族；**⬜ 字段布局——静态不可得**（哈希注册，xref 关闭，32 LogBook L1）；✅ 观测通道官方可搭（§3.3）。
- **行动（动态路线，替代原六步的 xref 部分）**：
  1. ✅ 3K Ghidra 轻量工程（functions.json，禁 Reference）——函数表索引（已完成/构建中）
  2. **官方观测基线**：PendingBattle 事件 → AI 内战确认（human_involved==false + 攻防齐全）→ BattleCompleted 结算确认（§3.3）
  3. **PendingBattle 事件派发 hook**（@0x34A0378 事件名动态定位派发函数）→ 直写窗口（g3_material_static §3 方案 A 首选）
  4. 分叉判定行为差分：观测到「AI 内战被自动结算」→ 定位分叉点 → 投票/就绪块字段候选（动态）
  5. `get_modify_pending_battle` 动态验证（脚本可调性 → 官方翻盘点裁决）
  6. 旁观身份 SP 侧字段（动态：加载出战斗后 IsLocalPlayerSpectating 消费点观察）
- **判据**：AI 内战加载出战斗场景 + 旁观身份（对照 shogun2 四判据）。

### 3.3 观测通道搭建（★裁决性质——"官方可观测"是假设不是前提）

- **原理**：若官方事件对 AI-only 战斗派发 → 零成本观测；若不派发（shogun2 式引擎内结算）→ 外部挂钩兜底（31 §2 场景 A/B）。
- **证据**：🔶 推断（cdir `ai_only_battle_events` 分支存在，但**存在 ≠ 会派发**——shogun2 先例：AI 内战快速结算绕过脚本事件；BattleCompleted 对 AI-only 触发 ⬜ 未核实）。
- **行动**：obs_campaign.lua（work/obs_out/）按 4 完善点落地 + **场景 A/B 裁决**：正常游玩 + 看海态多回合 → 若 AI 内战发生（视觉/存档证据）但无事件日志 = **场景 B 实锤** → 观测转 frida 挂钩。
- **判据**：① BattleCompleted(ai_only=true) 行出现 → 场景 A（官方可观测成立）② AI 内战发生但零日志 → **场景 B（引擎结算绕过脚本事件）→ 外部挂钩**。
