# 全面战争：三国 — 战役/战斗机制（20_MECHANICS）

> 本文件为调研整理，非官方数据源；数值以游戏内为准。
> 标注约定：【已确证】= 多方资料确认；【推断】= 基于游戏机制合理推演；【待核实】= 未能确认的细节。

## 1. 战役基础：时间与回合

- 每回合推进一个季节；一年回合数：**一说 5 回合/年**（春夏秋冬 + 岁末）【推断，待核实：3DM《一年几回合》攻略存在但数值未读取；社区另有「一年 8 回合」MOD，佐证基础值 < 8】。
- 角色年龄随时间增长：出生 → 成年（可任官）→ 中年/老年（立绘变化）→ 死亡【已确证：世代系统】。
- 战役地图：中原 + 周边（凉州/并州/幽州/南中/交州随 DLC 扩展）【已确证：DLC 新增区域】。
- 季节影响：冬季补给/移动受限等【推断，待核实】。

- 外交信誉：毁约/背盟降信誉，影响后续谈判【已确证：通用机制】。
- 特殊外交资源：
  - 曹操「天子宠信」：颁布圣旨（25 点宠信换外交优势；5 点提升/10 点降低他人 15 点宠信）【已确证：萌娘百科数值】。
  - 董卓「威压」：恐吓式外交【已确证】。
- 谈判逻辑：交换筹码按双方「想要度」定价，AI 会评估军力/关系/信誉【推断：全战系通用】。
- 历史事件外交：讨董联军结盟、官渡站队等剧本化选择【推断，待核实】。

### 2.2 间谍系统【已确证：间谍存在，3DM《间谍用法及补员讲解》攻略】
- 间谍即**角色**：将本派系人物派往敌方派系/军队卧底【已确证：框架】。
- 间谍动作：获取军事情报、煽动叛乱、削弱满意度、策反/刺杀等【推断，待核实】。
- 风险：身份暴露 → 间谍被捕/被杀，外交恶化【推断】。
- 间谍角色等级越高行动成功率越高【推断】。
- 反间谍：AI 也会派间谍渗透玩家【推断】。

### 2.3 改革/科技树【已确证：改革系统核心】
- 改革点：每回合按研究产出积累（受建筑/人物加成）【推断，待核实】。
- 改革按主题分支组织，五行对应部分分支【已确证：金系改革对应冶金/制陶/纺织等手工业领域（百度百科）】：
  - 金：手工业/军备改良【已确证】
  - 木：农业【推断】
  - 水：水利/物流【推断，待核实】
  - 火：军事/征伐【推断】
  - 土：内政/建筑【推断】
- 南蛮改革树特殊：**经济/军事/政治三大分支**，驯象之术为全树前置，T1-T4 四级；前三级的每分支含 3 项小改革 + 2 项大改革（小改革任选其一可解锁对应大改革二选一）【已确证：萌娘百科】。
- 改革解锁兵种/建筑/官职/被动加成【已确证：见 11_UNITS.md 兵种解锁】。
- 部分改革有前置（前后置关系成树）【已确证：南蛮树；汉树推断】。

### 2.4 公共秩序【已确证：框架】
- 每省有公共秩序值，受**满意度、腐败、粮食、占领新地、法令、建筑**影响【已确证：全战通用；各因子权重【待核实】】。
- 秩序过低 → 叛乱（叛军部队出现）【已确证：通用机制】。
- 省法令（Decrees）：每省可颁布一条法令（如税收/秩序/产粮）【推断，待核实】。
- 镇压手段：驻军、建筑（治安类）、将领满意度、减少税收【推断】。

### 2.6 官职与宫廷【已确证：框架】
- **派系领袖**：Faction Leader，享领袖特质【已确证】。
- **储君（Heir）**：指定继承人；储君战死/废立影响继承与满意度【已确证：储君为官职系统一环】。
- **廷臣/官职**：可册封丞相、大将军、将军等官位（头衔体系），授予官职提升人物满意度并附带加成【已确证：3DM《官职头衔系统解析》】。
- 官位数量随改革/声望解锁【推断】。
- 称帝后国号变化（如公孙瓒称帝建「燕国」）【已确证：18183 报道「公孙瓒称帝建立燕国」】。
- 官职任命策略：把高官给高满意度需求/强力武将，平衡忠诚与能力【推断】。

### 2.7 称帝与胜利条件【已确证：称帝机制存在；具体数值待核实】
- 流程：声望达标（数值【待核实】）→ 触发「称帝」抉择 → 成为皇帝 → 若 AI 也称帝则形成**三帝并立**【已确证：三帝并立为公开设定】。
- 胜利条件（称帝后）：占领另外两位皇帝的都城 + 声望满（具体数值【待核实】；3DM《称帝后胜利条件》攻略存在）。
- 袁术可提前僭号称帝（代价大）【推断，见 10_FACTIONS.md】。
- 非称帝胜利路线：短期战役目标/统一（是否可选【待核实】）。

## 3. 战斗机制

### 3.1 战斗基础【已确证：全战系实时战术战斗】
- 战场实时指挥：部署阶段（布阵）→ 交战；支持暂停/慢动作（非铁人模式）【已确证：通用】。
- 无海战：三国无海军战斗，河流通过渡口/浅滩跨越【已确证：无海战为公开设定；渡口细节【推断】】。
- 战斗类型：野战、攻城战、伏击战、夜战【已确证：脚本 API 中有 ambush_battle/night_battle 等（见 00_3K_EXTRACT_RECORD.md）】。
- 自动战斗（快速结算）：可跳过手动操作【已确证：全战通用】。

### 3.2 阵型与技能【已确证：阵型/技能存在；具体名单待核实】
- 部队有阵型（如圆阵、方阵、盾阵等）与主动技能（火矢、齐射、激励、突袭等）【推断：具体阵型/技能名【待核实】】。
- 阵型提供被动加成（如反骑、防御）【推断】。
- 技能有冷却与使用时机管理【推断】。

### 3.3 士气（Morale）【已确证：核心机制】
- 士气受**将领光环、侧翼受击、伤亡比例、冲锋、恐惧、友军溃败**影响【已确证：全战通用公式】。
- 士气归零 → 溃逃（Rout）；溃逃部队可被重整（Rally）【已确证：通用】。
- 演义模式下士气更稳（武将影响大）；史实模式更易崩溃【已确证：模式差异，见 11_UNITS.md】。
- 单挑胜负直接大幅影响双方士气【推断：见 §3.5】。
- 士气管理手段：留预备队、斩将、包围侧翼、恐惧源（兽兵）【推断】。

### 3.4 冲锋与近战【已确证：通用机制】
- 冲锋（Charge）：冲锋加成（Charge Bonus）在接触瞬间生效，骑兵/冲击型兵种收益最大【已确证：全战通用】。
- 本能（火）属性提升冲锋与近战攻击【已确证：属性效果，见 12_CHARACTERS.md】。
- 背后/侧翼攻击有额外伤害与士气惩罚【已确证：通用】。
- 演义模式武将冲锋/技能输出核心【推断】。

### 3.5 武将单挑（Duel，仅演义模式）【已确证：模式专属机制】
- 演义模式武将可发起/接受单挑【已确证】。
- 单挑过程为武将间对决（自动/手动演出），胜负影响士气与武将存亡【已确证：框架；演出细节【待核实】】。
- 史实模式无单挑（武将带亲卫）【已确证】。
- 单挑策略：以强凌弱（如吕布单挑敌将）、避免高价值武将冒险【推断】。

### 3.6 远程与弹药【已确证：机制存在；数值待核实】
- 弓/弩单位有弹药上限，射空后只能近战/待命【已确证：全战通用】。
- 智略（水）属性提升弹药与远程伤害【已确证：属性效果】。
- 弹药补充手段（军师技能/补给）【待核实】。
- 火矢（火焰箭）可点燃建筑/造成持续伤害【推断，待核实】。

### 3.7 攻城战【已确证：机制存在】
- 围城：围城数回合可迫降/强攻【已确证：通用】。
- 攻城器：投石机破墙、冲车破门、攻城塔/云梯登城【已确证：见 11_UNITS.md】。
- 守城方：城墙部队 + 箭塔/火油等防御设施【推断，待核实】。
- 胜利条件：占领中心点或全歼敌军【已确证：通用】。
- 围城饥饿：断粮导致守军损耗【推断，待核实】。

### 3.8 编队与指挥【已确证：框架；细节推断】
- 战斗编组：玩家可编组（Control Groups）与阵型预设，战斗中快速切换【推断：全战系通用】。
- 将领光环：武将影响范围内部队获得士气/属性加成（范围与数值【待核实】）。
- 侧翼包抄/背冲是核心战术；包围可造成士气崩溃【已确证：通用】。
- 战斗结算后可选择「追击/撤退休整」，追击扩大战果但损耗部队【推断】。

## 4. 时代推进（182 → 190 → 194 → 200 → 291）

- 各剧本独立战役，**不跨剧本继承进度**；「时代推进」体现为：①回合制时间流逝；②历史事件触发；③人物生老病死与继承【已确证：框架】。
- 190 剧本内可玩到 200 年之后：董卓之乱 → 诸侯混战 → 官渡之战事件（是否脚本触发【推断，待核实】）→ 赤壁之战【待核实】。
- 182（受命于天）：汉灵帝在位 → 184 黄巾起义事件 → 汉室存亡抉择【已确证：DLC 主题】。
- 194（弃叛之世）：吕布与孙策崛起【已确证：DLC 主题】。
- 200（命运分歧）：官渡之战（曹操 vs 袁绍）为核心【已确证：DLC 主题】。
- 291（八王之乱）：西晋宗室内战，独立于三国时间线【已确证：DLC 主题】。
- 关键历史事件（讨董联军、王允连环计、官渡、赤壁）在战役中的呈现方式【待核实：部分以事件/任务链形式存在（推断）】。
- 时间节奏：演义模式下角色寿命长（无双武将可战到老），史实模式武将更易早逝【推断】。
